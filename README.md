# Climate Lab

Climate Lab is a small interactive dashboard for exploring weather and climate data from CSV files. It brings together six Python experiments covering heat records, city comparisons, location searches, climate analysis, sensor checks, and station summaries.

The dashboard works with historical snapshots included in this repository. It is for exploring recorded data, not for live weather updates or forecasts.

The web dashboard has six sections:

1. **Station objects** — inspect high-temperature records for selected cities.
2. **City comparison** — compare May temperature readings across cities.
3. **Locations and alerts** — search the location snapshot and view heat alerts.
4. **Climate analyzers** — explore temperature, rainfall, air quality, humidity, and regional data.
5. **Sensor monitor** — check station readings for warnings and missing or invalid values.
6. **Climate summary** — compare summaries for selected Telangana stations.
